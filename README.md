🌿 Biodiversity Data Management System

A web-based Biodiversity Data Management System developed using PHP, MySQL, HTML, CSS, and JavaScript. The system provides an interactive administrative dashboard for organizing, monitoring, and managing biodiversity records such as Bird, Bat, Flora, and Transect data.

It also includes user account management features that allow administrators to view, manage, archive, delete, and lock user accounts and database records through a centralized dashboard.

🚀 Features
📊 Interactive administrative dashboard
🐦 Bird species record  management
🐦 Bird species record IUCN Status management
🦇 Bat species record management
🌱 Flora record management
🗺️ Transect record management
👥 User account management
📦 Archive records
🔍 View and manage biodiversity data
📈 Dashboard statistics and record counts
🗄️ Centralized database management

🛠 Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL
Server: Apache
Development Environment: XAMPP
UI: Bootstrap / Custom CSS

📂 Data Categories

The system manages different types of biodiversity records:

Category	Description
🐦 Birds	Bird species and observation records
🦇 Bats	Bat species and observation records
🌱 Flora	Plant and flora records
🗺️ Transects	Transect and biodiversity survey records
